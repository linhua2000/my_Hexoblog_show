发表于2026-08-26|更新于2026-08-27|工具与技能博客搭建

作为一名嵌入式 / IoT 学习者，拥有一个属于自己的技术博客，既是知识沉淀的宝库，也是未来求职的加分名片。本文详细记录了我在 2026 年 8 月 从零开始搭建 Hexo 博客的全过程，包含大量命令和避坑指南，适合所有技术初学者参考。

📌 为什么选择 Hexo 生态？

在对比了 WordPress、Hugo、VitePress 等方案后，我选择 Hexo + Butterfly 主题的理由如下：

  1. 极客风与低门槛：只需 Markdown 就能写作，无需折腾 CSS/JS。
  2. 中文社区活跃：大量的中文文档和主题，遇到问题容易找到解法。
  3. 免费部署：结合 Gitee/GitHub Pages，完全零成本。
  4. 局部安装友好：便于不同项目管理，避免全局环境冲突。

❓ 第七步：常见问题 FAQ

Q1：运行 hexo s 后浏览器显示 extends includes/layout.pug 代码怎么办？

这是典型的 hexo‑renderer‑pug 未安装或未生效导致的。请执行

并重新生成。

Q2：部署到 Gitee 后，页面样式丢失或显示纯文字？

检查根目录 _config.yml 中的 url 配置是否与 Gitee Pages 分配的地址完全一致，有时因资源引用路径错误导致 CSS 加载失败。

解决：将 url 设置为 https://你的用户名.gitee.io。

Q3：修改主题配置后刷新页面没变化？

修改 themes/butterfly/_config.yml 后，需要重启 Hexo 服务（Ctrl+C 停止再运行 npx hexo s）或重新生成才能生效。
