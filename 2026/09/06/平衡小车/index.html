平衡小车（直立环 + 速度环串级调参）

发表于2026-09-06|更新于2026-09-06|嵌入式学习笔记
|浏览量:

这是一篇个人向的调参记录。我用 STM32F103C8T6 + MPU6050（DMP 解算） 把一辆两轮平衡小车从「根本站不住」调到「能稳定直立、能被推动后自己回正」。把过程整理成教程，是为了让后来的学弟学妹少走弯路——很多坑看起来是玄学，其实都是极性、时序和调参顺序的问题。

两轮平衡小车用的是串级 PID：

  • 内环（直立环）：角度环，本质是 PD，让车「站住」。
  • 外环（速度环）：本质是 PI，抑制小车缓慢溜走，让车「钉在原位」。

调参口诀一句话：先极性、后大小；先直立环、后速度环。

踩过的坑：姿态角度在哪读、别被打断

mpu_dmp_get_data() 会通过 I2C 从 MPU6050 的 DMP 里读出解算好的姿态角（pitch / roll / yaw）。这个函数耗时较长（毫秒级），而且读取期间不可被打断——一旦在读取过程中被更高优先级的中断抢占，就会引入额外延时，角度环拿到的是一个「滞后/不连续」的角度，车会莫名发抖甚至失控。

我的做法是把它放在控制节拍的定时器中断里读取，并保证读取过程中不被更高优先级的中断打断：

也有一种常见的替代做法：定时器中断里只置标志位，把 mpu_dmp_get_data() 放到主循环里读，两种都行，关键是别让读取过程被打断：

提示：角度环用到的角度必须是「干净、最新」的。姿态读取的时序没安排好，后面调参时你会觉得参数怎么调都不对——先排除这个因素。

准备工作：先找「机械中值」

为什么要机械中值

角度环的输入是倾角。我们当然希望「车真正直立」时角度环输出为 0，但由于装配误差、重心位置、传感器零点漂移，整车的自然平衡点往往并不是 0°，而是某个小角度。

如果直接把原始 pitch 当控制输入，直立环会把「已经直立但 pitch ≠ 0」误判成「在倾斜」，于是车会朝着一边偏倒。所以调直立环之前，先要测出这个机械中值，把它校准掉。

测量步骤

先把小车断电，用手轻轻扶住车身，让车轮刚好接触水平地面（如桌面），此时车体处于自然直立状态，不要人为施加外力。

  1. 前倒测试：慢慢将车体向前推（绕电机轴向前旋转），直到它因重心前移而自然向前倒下，记录下倒下瞬间的角度（例如 +2°）。
  2. 后倒测试：同样将车体向后拉，直到它自然向后倒下，记录倒下瞬间的角度（例如 -3°）。
  3. 取中值：两个倒下角度的平均值，就是机械中值。

机械中值 =（前倒角度 + 后倒角度）÷ 2

直立环（角度环，内环 PD）

直立环让车「站住」。它本质是一个 PD 控制器：比例项用倾角决定回正力度，微分项常用陀螺角速度做「阻尼」，抑制角速度、防止过冲。

调直立环的顺序是：先调 Kp 极性 → 再调 Kp 大小 → 再调 Kd 极性 → 再调 Kd 大小。极性错了再怎么调大小都白搭。

1. Kp 极性

  • 极性错误：小车往哪边倒，车轮就往反方向开，会使得小车加速倒下。
  • 极性正确：小车往哪边倒，车轮就往哪边开（朝倾倒的方向「追」），这样车轮才能跑到重心下方，给车一个回正的趋势。

2. Kp 大小

极性确定后，把 Kp 从 0 开始一直加大，直到出现大幅、低频的振荡（整车左右来回摇晃）。这个临界点说明比例项已经强到足以让车回正，Kp 就取在这一带。

3. Kd 极性

判据用「空中旋转测试」：拿起小车，绕电机轴旋转车体，观察车轮。

  • 极性错误：车轮反向转动，无跟随。
  • 极性正确：车轮同向转动，有跟随。

（1）为什么「同向转动」反而是正确的？

直觉上微分项是「抵抗角速度」的，车轮怎么反而跟着车体同向转？关键在于力矩的作用对象不同。

在真实地面正常行驶时，车轮转动会通过地面摩擦对车体施加力矩。车体向前倾 → 车轮向前转 → 通过地面给车体一个向后的反作用力 → 产生向后回正的力矩，从而扶正车体。所以「车轮向前转」的目的是产生「向后」的力矩——这是借助地面实现的。

但把车「拿在空中」时没有地面摩擦负载，车轮转动几乎不会对车体产生力矩，于是车轮只是「空转」跟随车体的转动方向，反映的其实是控制器试图抵抗角速度的意图。在真实地面，这种同向转动对应的正是正确的阻尼作用。

（2）如何验证极性正确？

  • 静止直立：极性正确时小车能稳定直立；极性错误时会疯狂朝一个方向加速倒下。
  • 空中旋转测试：用手快速转动车体，观察车轮方向。车轮与车体同向 = 极性正确；反向 = 错误。

4. Kd 大小

极性确定后，把 Kd 一直加大，直到出现高频振荡（轻轻触碰小车就剧烈抖动）。

注意：Kd 的绝对值经验范围大约在 0.1 ~ 0.9 之间。我调到 0.8 时就出现了高频振荡，此时一定要及时断电，防止电机及驱动烧毁。

5. 收尾：参数统一 × 0.6

直立环调试完毕后，把确定下来的 Kp、Kd 统一乘以 0.6 作为最终参数。

  • 原因：前面得到的 Kp、Kd 都是能让车立住的「临界/最大」值，根据工程经验，平衡小车更理想的参数大约是最大参数的 ×0.6。
  • 结果：乘 0.6 后抖动消失，但直立效果也会变差（车变「软」、回正力度不足）。这是正常的——等下面加上速度环，性能就能补回来。

速度环（外环 PI）

只靠直立环，车虽然「站得住」，但 PD 对角度差为 0 的情况没有输出，车会朝一个方向缓慢溜走。速度环（PI）就是为了抑制这种漂移：把车速/位移拉回 0，让车不仅站住，还钉在原位。

调参前注意

  1. 调【速度环参数极性】时，需要去掉【直立环运算】（注释掉），这样轮子的响应才不会被直立环干扰，能看清极性。
  2. 调【速度环参数大小】时，需要引入【直立环运算】，在真实闭环下验证效果。
  3. 调极性之前，先确认编码器读数正负与 PWM 输出的正反转是否一致，否则判断会被误导。
  4. 【转向环】整个调试过程始终处于关闭状态；若已提前调好参数，没注释影响也不大。

Kp & Ki

网上常用的线性关系：

Ki = Kp ÷ 200

即 Ki 跟着 Kp 按比例取即可，只需要调 Kp。

Kp & Ki 极性（此时直立环已注释）： 手动转动其中一个车轮，观察另一个轮：

  • 极性错误：另一个车轮会以同样速度反向旋转——典型负反馈。
  • 极性正确：两个车轮会同向加速，直至电机最大速度——典型正反馈。

说明：这个「正确 = 正反馈跑飞」的现象和直觉相反，它验证的其实是编码器与 PWM 的符号链路是否一致。链路一致时，闭环里速度环才能把漂移正确拉回 0。

调参流程

  1. 先调 Kp 大小：引入直立环后，把速度环 Kp 一直加大，直到「推动小车时小车能停下，但同时又出现抖动」。
  2. 回调角度环 Kd：用角度环的 Kd 把这个抖动抑制下去。
  3. 最后加速度环 Ki 微调：把 Ki 补上做微调。

转向环（待更新）

转向环（让小车左右转向/保持朝向）本次尚未调试，调试时保持关闭。后续更新。

总结

整个调参可以概括成一条流水线：

  1. 找机械中值，校准 pitch，统一用 actual_pitch 做控制输入。
  2. 调直立环（PD）：Kp 极性 → Kp 大小（到低频大幅振荡）→ Kd 极性（空中旋转同向）→ Kd 大小（到高频振荡）→ 整体 ×0.6。
  3. 调速度环（PI）：调极性时去掉直立环、调大小时加回；先 Kp 到「推动停下且抖动」，回调角度环 Kd 抑制，最后加 Ki 微调。
  4. 转向环：保持关闭，待更新。

安全提醒：调参时出现高频剧烈抖动要立刻断电，防止电机与驱动烧毁；同时注意手和线别卷进轮子。
